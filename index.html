Common questions

What is Fender Studio Pro MCP?

It is an independent, open-source Model Context Protocol server. A local MCP client connects to an installed bridge in Studio Pro and calls tools for editing and reading the current song.

How the bridge works

Which computers and app versions are verified?

Live verification covers macOS on Apple Silicon with Fender Studio Pro 8.1.1, build 113103. Windows, Intel Macs, and Linux are outside the verified host scope.

Live validation report

What do I need to connect?

Build the local server, install the Studio Pro bridge, and configure a control surface. Use an MCP client that supports local stdio servers and run the live connection check with a scratch song open.

Step-by-step setup

When do I need the native add-on?

Install it for native plug-in parameter access, supported state and preset operations, and advanced insert routing. The add-on targets the verified Apple Silicon host build.
