자주 묻는 질문

Fender Studio Pro MCP는 무엇인가요?

독립 오픈소스 Model Context Protocol 서버입니다. 로컬 MCP 클라이언트가 Studio Pro에 설치한 브리지에 연결해 현재 송을 읽고 편집하는 도구를 호출합니다.

브리지의 동작 방식

어떤 컴퓨터와 앱 버전에서 검증했나요?

Apple Silicon Mac의 Fender Studio Pro 8.1.1 빌드 113103에서 실앱 연동을 검증했습니다. Windows, Intel Mac, Linux의 실앱 연동 상태는 아직 확인되지 않았습니다.

실앱 검증 보고서

연결에 무엇이 필요한가요?

로컬 서버를 빌드하고 Studio Pro 브리지와 컨트롤 서피스를 설정하세요. 로컬 stdio 서버를 지원하는 MCP 클라이언트를 사용하고, 시험 송을 연 상태에서 연결을 검사합니다.

단계별 설치 안내

네이티브 애드온은 언제 필요한가요?

네이티브 플러그인 파라미터 조회와 변경, 지원되는 상태·프리셋 동작, 인서트 라우팅을 사용하려면 설치하세요. 검증된 Apple Silicon 앱 빌드를 대상으로 합니다.
