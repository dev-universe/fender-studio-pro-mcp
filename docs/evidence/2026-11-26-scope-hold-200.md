# Scope maximum-window display with 200 percent Hold

R432 used Studio Pro 8.1.1 Build 113103 on macOS arm64. A fresh
owned scratch reused R423's stopped, muted stereo route, 41.3 Hz
sine at −7.50 dB, 37.5 percent rising threshold, source A Main
Left, max `8000.0 smp` time scale and zero Position. Main and
the audio track were at zero. The other 40 armed DSP and display
rows matched the archived R423 comparison.

With Tone Off, the exact Scope DSP formatter confirmed the
current 100 percent and two intended 200 percent representations.
A single raw-bit write changed Hold to 200 percent before arming
Oneshot. The independent read matched raw
`409F400007D00000`. The Scope editor showed 200 percent Hold
and a trigger label of `160000 smp`. The waveform initially
remained flat. [Detector and Hold analysis](https://github.com/dev-universe/fender-studio-pro-mcp/pull/219)

| Relative frame request interval | Scope display |
| --- | --- |
| −258 to −182 ms | Flat across the canvas |
| 811 to 891 ms | Oscillation across part of the canvas and a flat suffix |
| 1,901 to 1,984 ms | Full-width waveform |
| 2,721 to 2,796 ms | Same full-width waveform |
| 4,601 to 4,672 ms | Same full-width waveform after verified Tone Off |

Both full-width frames before Off and the full-width frame after
Off returned identical screenshot byte arrays. The scheduled On
and independent read were bracketed by about 2–132 ms. The Off
request and read were bracketed by 3,330–3,528 ms. A further read
confirmed Off by 3,596 ms. All times are relative to the scheduled
On target.

This matched 200 percent trial retained its rendered trace across
the compared frames. In the earlier 100 percent trial the full
frames changed and the subsequent Off frame had a flat middle.
This supports a visual difference over the measured intervals.
Exact internal trigger, completion time, actual engine rate, and
hidden buffer contents remain open. [R423 comparison](https://github.com/dev-universe/fender-studio-pro-mcp/pull/214)

Tone Off, Hold 100 percent, flat display and all 41 typed settings
were independently restored. The route and mixer matched. The
owner made 96 requests in 84.972 seconds. The normal app exit
followed 143.256 seconds. The scratch was closed without saving.
Original file hashes, 18 managed files and ten restored app profile
files were verified.
