# 작업 재개 안내

현재 작업은 **2026-11-12 사용자 요청으로 재개해 진행 중**이다. 자동 재개나 예약 실행은 없다.
최신 완료 단위와 다음 작업은 [재개 진행 기록](PROGRESS_2026-11-12.md)과 `RESUME_STATE.json`을 읽는다.
2026-11-10 중단 시점에는 읽기 검증 단위를 마친 후 Studio Pro와 MCP 소유 프로세스를 종료했다.

사용자가 **“진행 재개해”**라고 하면 다음 순서로 이어간다.

1. 저장소 `AGENTS.md`를 읽는다.
2. [이번 루프 전체 인수인계](LOOP_HANDOFF_2026-11-10.md)를 끝까지 읽는다.
3. [재개 진행 기록](PROGRESS_2026-11-12.md), [재개 상태 파일](RESUME_STATE.json)과 실제 Git·프로세스·설치 파일 상태를 대조한다.
4. 최신 `RESUME_STATE.json`의 `next_units_in_order`부터 이어간다. 이전 인수인계의 완료된 시작 순서나 전수 검사를 반복하지 않는다.
5. 단위 작업 완료 때마다 완료·진행·남은 항목을 체크리스트로 알린다.

사용자가 같은 표현을 다른 대화에서 사용하더라도 이 저장소의 작업을 재개하는 문맥이면 같은 절차를 적용한다.
이 안내는 중단 중에 스스로 실행하라는 지시가 아니다. 새로운 중단·범위 변경 지시가 우선한다.

2026-11-12 unit63 완료·Native34 설치 준비 시점의 핵심 상태는 다음과 같다.

- 마지막 실제 검증은 Native33 제품 소스 `045c458`의 도구42개로 수행했다. Native34와43개 도구 실행 파일은 검토·빌드 후 설치를 준비하고 있다.
- Chorder 입력 음정 왕복과 Mode 왕복, 저장 없는 완전 재시작 후 전체908개 원본 복귀를 검증했다.
- 추가 프리셋46종 계획에서18종을 완료했다. capsule 단독16종·32사례와 Expander·Gate hybrid2종·4사례다.
- 총 긍정 사례는36개이며 잔여28종에는 capsule 복원 실패 후 중단한 Multiband Dynamics·Surround Delay·Room Reverb가 포함된다.
- 마지막 실제 단위는 unit63 Analog Delay 완료와 Room Reverb 중단이다. 저장 없이 닫은 뒤 앱과 owner의 종료를 확인했다.
- Native33은 `pitch61`의 로컬 메타데이터 두 개를 실제8.1.1에서 읽었다. 쓰기 권한이나 MIDI 음정 매핑을 확정한 결과는 아니다.
- 다음은 Native34 저장 코드 getter 설치·실제 검증, 일반 효과9종과 나머지 프리셋, 저장된 코드 편집 순서다.
- 이전 native 빌드의 runtime token과 instance 바인딩을 재사용하지 않는다. 완료 증거는 다시 실행하지 않고 보존한다.
- PR #4는 Draft로 유지한다. 미완료 범위를 전체 지원으로 승격하지 않는다.

단위 종료마다 실제 소요 시간과 잔여 수, 전체 남은 시간 범위를 함께 알린다.
현재 추정은6~17시간이며 신뢰도는 낮다. 모델·중첩 그래프와 전용 역할의 범위가 아직 불확실하다.
하드웨어가 필요한 External·CV 검증은 별도 조건이다.

상세 기록은 [플러그인 상태 검증](PLUGIN_STATE_VALIDATION.md), 전체 최초 계획은
[구현 계획](IMPLEMENTATION_PLAN.md)에 보존한다. 최초 계획의 오래된 체크박스만 보고
현재 완료 여부를 판단하지 않는다.
