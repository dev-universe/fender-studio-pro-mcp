# 작업 재개 안내

현재 작업은 **사용자 요청으로 중단된 상태**다. 자동 재개나 예약 실행은 없다.
2026-11-10에 진행 중이던 읽기 검증 단위를 마친 후 Studio Pro와 MCP 소유 프로세스를 종료했다.

사용자가 **“진행 재개해”**라고 하면 다음 순서로 이어간다.

1. 저장소 `AGENTS.md`를 읽는다.
2. [이번 루프 전체 인수인계](LOOP_HANDOFF_2026-11-10.md)를 끝까지 읽는다.
3. [재개 상태 파일](RESUME_STATE.json)과 실제 Git·프로세스·설치 파일 상태를 대조한다.
4. 인수인계의 **재개 직후 실행 순서**부터 시작한다. 이미 검증한 전수 검사를 처음부터 반복하지 않는다.
5. 단위 작업 완료 때마다 완료·진행·남은 항목을 체크리스트로 알린다.

사용자가 같은 표현을 다른 대화에서 사용하더라도 이 저장소의 작업을 재개하는 문맥이면 같은 절차를 적용한다.
이 안내는 중단 중에 스스로 실행하라는 지시가 아니다. 새로운 중단·범위 변경 지시가 우선한다.

중단 시점의 핵심 상태는 다음과 같다.

- 제품 소스는 `486d611`이다. 이후 인수인계 문서 커밋은 기능 변경이 아니다.
- Rust MCP 도구 42개와 네이티브 빌드 31을 설치했다.
- 마지막 실제 단위는 Chorder 학습 getter의 Mode-off 읽기와 전체 908개 원본 비교다.
- getter는 125개 뷰를 완전히 탐색했다. 학습 setter는 아직 실제 앱에서 호출하지 않았다.
- 다음 실기 단위는 새 바인딩을 만든 뒤 Mode-off 입력 음정 `null → MIDI 0 → null`을 검증하는 것이다.
- Mode 쓰기 전에 Mode-on 탐색 수와 새로운 복원 바인딩을 별도로 측정해야 한다.
- 추가 프리셋 46종 중 Mixtool·Binaural Pan을 마쳤다. 나머지는 44종이다.
- PR #4는 Draft로 유지한다. 미완료 범위를 전체 지원으로 승격하지 않는다.

상세 기록은 [플러그인 상태 검증](PLUGIN_STATE_VALIDATION.md), 전체 최초 계획은
[구현 계획](IMPLEMENTATION_PLAN.md)에 보존한다. 최초 계획의 오래된 체크박스만 보고
현재 완료 여부를 판단하지 않는다.
