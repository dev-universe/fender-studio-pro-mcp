## CV 프리셋의 별도 출력 연결 데이터와 저장 소유 구조

설치된 CV default.preset은2174바이트 ZIP이며 metainfo.xml·data.fxpreset·PortSetup.data를 포함한다. 클래스와 선언된 DSP 데이터 파일이 CV Instrument에 맞는다. 별도315바이트 PortSetup.data에는 Output03의 비어 있지 않은 연결 하나가 있다. 따라서 이 패키지를 파라미터만 담거나 모든 출력이 None인 프리셋으로 취급하지 않는다. 메타데이터의 Fender 표시는 인증된 factory 출처 증명이 아니며 공식 설치본 대조는 생략한 상태다.

저장된 소유 Scratch의 CV wrapper에는 별도 PortSetup의 Output01..06 UID 여섯 개가 있고, 해당 저장 노드에는 assignment가 없다. DSP ComponentData와 호스트 설정은 구조상 분리돼 있다. 저장된 Music 입력은 AllInputFilterOUT이므로 과거 실제 None 관찰과 구분한다.

Main에서 PortSetup.data의 저장·로드 후보와 AudioFXPortSetup의 하위 요소 로더를 확인했다. 초기 조사에서는 인접 테이블 때문에 PortList/PortList.Micro callback으로 해석했으나, 아래 후속 조사에서 별도 전역 preset extra-content callback으로 정정했다. 현재 catalog Presets IDataTarget에서 그 경로로 연결되는지는 미확인이므로 직접 recall 소비 경로로 단정하지 않는다. CV component-alias IStorable이 출력 None을 보존하는지도 미확인이다. [정적 근거](evidence/2026-11-17-cv-preset-port-ownership-static.json)에 한계를 함께 보존했다.

Ghidra 조사 전체524.591초·실제DAQ0이다. worker30개 및 Root archive2개 증거를 내보내고 모든 분석 target을 닫았다. 원래 checkpoint·앱·저장본·제품 소스는 보존했다. 고정15/43완료28잔여·소프트웨어24/하드웨어4를 유지하며 다음 호출 연결 조사는10~20분 예상이다. 전체 종료는 미해결 연구와 하드웨어 대기로 유한하게 산출하지 못했다.


## CV 프리셋의 호스트 문맥과 별도 포트 복원 호출 연결

후속 정적 조사에서 타이머 테이블과 바로 옆의 두 항목 포트 저장·복원 테이블을 분리했다. 정확한 IID 대조 결과 앞 테이블은 ITimerTask이며 preset mediator가 아니다. 포트 설정 callback 객체는 전역 preset handler 목록에 등록된다. 패키지 본문을 복원하는 native 함수는 그 뒤 동일한 목록의 별도 콘텐츠 복원 함수를 호출한다. 따라서 첫 조사에 쓴 PortList callback 해석은 대체한다. 기존 원본 보고서는 수정하지 않고 정정 근거를 추가했다.

실제 AudioSynthSlot의 IPresetMediator는 정확한 IID와 생성자·복원 thunk로 식별했다. 복원 동안 slot을 담는 전역 문맥과 PortSetup loader gate가 읽는 전역이 동일하다. 이는 호스트 문맥과 별도 콘텐츠 호출의 정적 연결이다. 현재 MCP가 보유하는 CV catalog 항목의 실제 타입, IDataTarget 삽입 구현, 특수 분기, port gate의 실제 통과 여부 및 여섯 None 보존은 아직 미확인이다. preset apply와 capsule load는 계속 실행하지 않는다.

공개 CCL의 [PresetFile 구현](https://github.com/cclsoftware/ccl-framework/blob/8a8cab590b1a2e10cdef3df76ea4b2739c92121f/ccl/app/presets/presetfile.cpp#L613)과 구조가 일치하지만, 공개 소스와 설치된 8.1.1의 소스 버전이 동일하다고 단정하지 않는다. 별도 콘텐츠 callback의 반환값을 호출 loop가 사용하지 않는 것도 확인했다. 요청 수락을 실제 효과 성공과 구분하는 기존 제품 의미를 유지한다.

전체 조사 경과564.510초, 새 함수 본문19개, 실제DAQ0이다. 본문 목표12개를7개 초과한 이유를 기록했으며900초 상한은 지켰다. REA 증거37개를 내보내고 엔진 close·reset·EOF exit0을 확인했다. 원본 실행 파일·checkpoint·제품 소스가 같은 해시다. [정적 호출 근거](evidence/2026-11-17-cv-preset-extra-content-dispatch-static.json)에 관찰과 추론 및 미확인을 분리했다.
