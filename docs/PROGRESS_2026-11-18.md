# 2026년 11월 18일 진행 기록

## 이번 실행의 범위와 마감

사용자가 작업 재개와 공개 저장소 기본 보호 설정, 검증된 구현의 메인 병합, README 갱신을 명시적으로 요청했다. 이전 Draft 유지 지시는 이번 검토·병합 범위에서 해제되었다. Volt 276과 Keystation88 MK3는 이전과 같은 USB 연결이며 루프백 배선이 추가되었다는 증거는 없다. 하드웨어 연결 해제 및 맥북 이동 마감은 **2026년 11월 18일 오전 6시 한국 시간**이다. 지난 실행의 오후 6시 마감을 재사용하지 않는다.

저장소 공개 준비를 먼저 수행하고 이후 기존 CV 대기열과 가능한 하드웨어 확인을 이어간다. 오전 5시 30분부터 새 실시간 단위를 시작하지 않으며, 5시 45분까지 앱·owner·분석 엔진 정리를 마치고 6시까지 문서와 Git 기록을 마감한다. 완료 단위마다 실제 시간, 체크리스트, 잔여 수와 예상 시간을 보고한다. 고정 플러그인 대기열은 43개 중 15개 완료·28개 잔여이며, 저장소 정비 단위를 이 수에 더하지 않는다.

## 공개 저장소 보호 설정

GitHub API에서 설정을 변경한 뒤 다시 조회했다. 저장소는 공개를 유지하며 기존 관리자 한 명의 권한을 유지했다.

- main은 Pull Request 경유만 허용하며 관리자에게도 보호를 적용한다. 강제 푸시와 삭제를 허용하지 않는다.
- 최신 main 기준의 `Core offline checks`, `macOS arm64 native checks`를 필수로 지정했다. 두 검사는 GitHub Actions 앱의 검사로 한정한다.
- 대화 해결을 요구한다. 단독 관리자 저장소이므로 필수 승인 인원은 0명이며 독립 검증 결과를 별도로 남긴다.
- Actions 기본 토큰은 읽기 권한이며 Pull Request 승인을 허용하지 않는다. GitHub 소유 Actions만 허용하고 모든 외부 기여자의 실행에는 관리자 승인을 요구한다.
- 비밀정보 검사와 푸시 보호는 기존 활성 상태를 유지했다. 취약점 알림, Dependabot 보안 수정, 비공개 취약점 제보를 활성화했다. 병합한 브랜치의 자동 삭제를 켰다.

설정은 코드 검증 결과가 아니다. 원격 CI와 독립 검토가 통과하기 전에는 병합하지 않는다.

1. 저장소 보호·보안 설정: 완료, 원격 재조회 확인.
2. CI·기여/보안 안내·README: 작성과 로컬 검증 완료, 원격 CI 진행 중. README 첫 줄을 비개발 음악인을 위한 한국어 설명으로 바꾸고 오래된 진행 수와 링크를 수정한다.
3. 기존 PR4 독립 검토·필요 수정·원격 검사·메인 병합·병합 후 확인: 진행 중. CLI 일반 변경 요청의 문서 토큰 사전조건 누락을 독립 검토가 발견해 별도 유한 수정 대상으로 분리했다. 이 경로를 수정·검증하기 전에는 출시하지 않는다.

## 공개 준비 중 확인한 수정

- 모든 변경 요청의 문서 토큰을 공통 runtime에서 확인한다. CLI Call도 owner 시작 전에 검사한다. 특수 읽기 요청의 기존 문서 조건은 유지했다. 누락·빈 문자열·공백 요청의 대기열 미전달과 정상 읽기·정상 문서 요청을 오프라인 검증했다. 수정 후 Rust 1.88의 root 테스트 183개가 통과했다. 이는 DAW 실시간 검증 결과가 아니다.
- ZIP 라이브러리를 6.0.0에서 9.6.1로 고정했다. Rust 1.88과 deflate 전용 설정을 유지하면서 공개된 네 보안 권고의 수정 버전 범위를 충족한다. API 변경에 필요한 곡·프리셋 항목 이름의 오류 전파만 추가했다. 전체 183개 root 테스트가 통과했다. 메인 반영 후 GitHub의 경고 해소 여부를 별도로 확인한다.
- 네이티브 테스트의 C 문자열 리터럴 포인터 동일성 비교 두 곳을 문자열 내용 비교로 수정했다. 제품 네이티브 구현은 변경하지 않았다. 최적화·직렬 add-on 테스트 448개와 라이브러리 unit 289개·doctest 20개, 패키지 빌드를 통과했다. 부하가 있던 debug 검사의 실제 제한시간 초과 기록은 보존하며 제한시간을 늘리지 않았다.
- 현재 GitHub 앱 연결은 워크플로 파일 쓰기에서 403을 반환했다. 추가 권한이나 토큰을 만들지 않고 사용자의 기존 로그인 브라우저로 검사 파일을 게시했다. 게시된 바이트가 로컬 검증 파일과 일치함을 다시 확인했다.

## 최초 장치 인식 확인

오디오 스트림과 MIDI client를 만들지 않는 OS 메타데이터 조회에서 Universal Audio Volt 276 및 M-Audio Keystation 88 MK3를 확인했다. Volt는 입력 2채널·출력 2채널, 48 kHz·512프레임으로 표시되었다. 이는 DAW 엔진 선택, 실제 건반 수신, 케이블 왕복 또는 들리는 효과를 검증한 결과가 아니다. 장치 UID와 원본 출력은 비공개로 보관한다.
